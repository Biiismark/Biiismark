# MarkFit

Aplicativo pessoal de treino em formato PWA, baseado em software livre e adaptado para português. O diretório [`markfit/`](./markfit/) contém o código-fonte e as adaptações do projeto.

## Licença

A aplicação MarkFit mantém as condições da licença GNU AGPL-3.0 do projeto-base NoBS, com os avisos de autoria preservados. Consulte `markfit/LICENSE` e `markfit/README.md`.
